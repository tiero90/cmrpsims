## Benchmarks and rules of thumb

| Topic | Gulati figure |
|---|---|
| Asset performance factors | Inherent reliability (design), operating environment, maintenance plan |
| Failures from operational errors | 40% or more |
| Planned work | ≥ 85% (Bab 4); best practice ≥ 90% (Bab 1) |
| Proactive work | ≥ 85% |
| Schedule compliance | ≥ 90%; schedule approved previous week or ≥ 3 days ahead; schedule 100% of craft hours |
| PM schedule compliance | ≥ 95% |
| 10% rule of PM | Complete within ±10% of the interval (30 days → ±3; 90 days → ±9) |
| Calendar-based PMs | ≤ 30% of all PMs |
| Backlog | 4–6 weeks |
| Rework | < 2% |
| Right parts delivered | ≥ 99% |
| Planner ratio | 1 planner : 15 ± 5 craftspeople |
| Wrench time | 25–65% across industries; North America ≈ 40%; good shop ≈ 60% |
| Planned vs reactive cost | Planned work costs 2–3× less |
| Critical assets | ≈ 25% ± 5% of assets (test answer: < 30%) |
| Asset utilization (world class) | > 85% (≈ 95% possible but very hard) |
| O&M share of life cycle cost | ≈ 70–80% or more; most O&M cost is fixed during design |
| Inventory carrying cost | ≈ 20–25% of item value per year |
| MRO inventory turnover | < 2 |
| ABC analysis | A items ≈ 20% of items, 70–80% of value |
| Service level | SL = 1 − stockout rate |
| EOQ | √(2DS/H); EOQ does not change the turnover ratio |
| Training budget | ≈ 5% |
| Failure patterns | < 20% age-related, ≥ 80% random; early airline data: 68% infant mortality |
| Inspection interval | Shorter than the P-F interval (rule of thumb ≈ ½ P-F) |
| Priority | Work priority = asset criticality (1–5) × work impact (1–5) |
| Criticality scale | 5 safety/protective · 4 critical to production · 3 support system · 2 standby in critical system · 1 other |
| Work impact scale | 5 immediate safety threat · 4 limits primary goals · 3 hazard, not immediate · 2 affects ops later · 1 efficiency |
| OEE / TEEP | OEE = A × P × Q (SMRP "OEE 2"); TEEP = utilization × OEE (SMRP "OEE 1") |
| Reliability / maintainability | Reliability measured by MTBF; maintainability by MTTR; availability = uptime ÷ (uptime + downtime) |
| Culture change | Takes many years; depends on time, not just resources |
| Metrics | Primary objective: change behavior; leading vs lagging depends on where applied; "manage the work, not the metric" |
| Benchmarking | Starts with internal analysis; internal benchmarking rarely gives breakthroughs; keep it legal (no price talk) |
| Planner must not be | Supervisor, QC inspector, expediter, clerk, emergency responder, help desk |
| Work order | Asset ID is the most important field; closed by the person who did the work, reviewed by supervisor |
| TPM pillars (8) | Autonomous maint., focused improvement, planned maint., quality maint., training, early equipment mgmt., office improvement, SHE |
| 5S / 6S | Sort, set in order, shine, standardize, sustain (+ safety) |
| RAMS2O | Reliability, availability, maintainability, safety, sustainability, operability |
| Leadership measurement | Kouzes & Posner LPI (observers rate behaviors); Campbell 6 leadership + 8 management factors; Mann's 4 behaviors |
| Sustaining reliability culture | Knowledge, teamwork, focus, planning, processes, measurements |
